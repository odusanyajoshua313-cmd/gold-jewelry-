# Goldplugdami

> Official e-commerce storefront for **Goldplugdami**, offering real 18k, 21k, 22k, and 24k gold jewelry and bars in Lagos, Nigeria, priced transparently by daily market rate and gram weight.

---

## Overview

Goldplugdami is a lightweight, responsive web application designed for fast mobile shopping and transparent gold pricing:

- **Daily Gold Rate Engine:** Dynamically calculates piece prices based on weight (grams) and daily karat market rates.
- **WhatsApp Direct Ordering:** One-click automated order inquiries with pre-filled piece details.
- **VIP Updates:** Newsletter integration for new arrivals and price changes.
- **Fast & Accessible:** Sub-second load times, mobile-optimized layouts, and zero-framework performance.

---

## Tech Stack

- **Frontend:** Semantic HTML5, Vanilla CSS3, Modern JavaScript
- **Hosting & Serverless:** [Vercel](https://vercel.com)
- **Database & Storage:** [Supabase](https://supabase.com) (PostgreSQL)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or newer recommended)

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/odusanyajoshua313-cmd/gold-jewelry-.git
   cd gold-jewelry-
   ```

2. Copy the environment variables template:
   ```bash
   cp .env.example .env
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:8000`.

---

## Deployment

This project is configured for continuous deployment with **Vercel**.

1. Connect this repository to your Vercel account.
2. Configure required environment variables listed in `.env.example`.
3. Deploy.
